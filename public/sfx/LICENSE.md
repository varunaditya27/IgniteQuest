# Sourced audio — licenses

Both files are Creative Commons 0 (public-domain equivalent) — free for
commercial use, no attribution required. Trimmed from their originals with
ffmpeg (fade-in/out only, no pitch/content changes).

- `drumroll.mp3` — trimmed from ["Long Snare Drum Roll with Cymbal Crash"](https://freesound.org/people/MissloonerVoiceOver255/sounds/569113/)
  by MissloonerVoiceOver255, freesound.org, CC0.
- `crowd-cheer.mp3` — trimmed from ["Crowd Cheering"](https://freesound.org/people/SoundsExciting/sounds/365132/)
  by SoundsExciting, freesound.org, CC0.

Every other in-game sound effect is synthesized at runtime via the Web Audio
API (`lib/sound/`) — no additional audio files.
